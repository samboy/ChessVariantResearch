Turtle Shell Games

This is an exploration of the Turtle Shell grid and abstract games which can be played on said grid. Right now we have two finished (i.e. playable) games:
  • Turtle Shell Chess (PDF file with full rules)
  • Turtle Shell Go
External links:
  • Turtle Shell Chess. External HTML copy of Turtle Shell rules.
  • Zillions rule file for Turtle Shell Chess
Other abstract games can be played on this grid, but these are the finished games with full rules that we have right now.
